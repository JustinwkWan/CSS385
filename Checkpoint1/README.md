Synopsis/Objective
Get out is a single player puzzle escape room game where the player is put into a scenario and tries to solve it before time runs out. 
Each room will have different clues and items that will help them reach the end of the scenario.
Players logical reasoning skills will be pushed to the limits as they find the way to escape. 
The objective of the game is to escape the scenario by using clues and solving complex puzzles that lead to the exit. 

Game Mechanics
Multiple Rooms - There will be multiple rooms within each scenario with some clues being found out through finishing the puzzle in the 
previous room. 
Items - Players are able to hold items such as letters, keys, or other scenario items to trace back a previous clue they have found. 
Solving Puzzles - The player will have to use their clues and logical thinking skills to solve the super hard puzzles :O.
Story - Each scenario will have a different scene so the player is able to have a different experince every time they play. 
However, I believe the creating the graphics may be too hard to do that for now so I believe it will be easier to use already created 
assets or reuse assets for multiple rooms but with different story lines. 
Optional Hints - If the player is stuck, they can request a hint, it will hurt their score!
